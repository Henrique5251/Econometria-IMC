# Econometria-IMC
Repositório com a base de dados e o script no R  do artigo empírico
## Como reproduzir:
1. Baixe o repositório (botão Code -> Download ZIP) e deixe o script e a base na mesma pasta.
2. Caso necessário, instale os pacotes uma única vez:

   install.packages(c("readxl", "dplyr", "lmtest", "sandwich", "car", "modelsummary"))
   
3. Abra o script no RStudio e clique em Session -> Set Working Directory -> To Source File Location.
4. Rode o script inteiro.
